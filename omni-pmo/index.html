What runs before a screen exists

Apps Script · V8 No server, no bundler
1
Intake

Vendors email daily production reports as spreadsheets in whatever shape they use. A Power Automate flow drops them into a watched Drive folder and a timed trigger discovers new files. Deliberately not a webhook, because a few seconds of latency is worth not owning a receiver.

Drive discovery · timed trigger
2
Schema mapping

Every vendor names columns differently and changes them without warning. One adapter resolves headers by alias rather than position, so a shifted or renamed column degrades to a warning instead of silently writing footage into the wrong field.

createSchemaAdapter
3
Matching and dedup

Project IDs arrive misspelled, transposed, or with the wrong market prefix. Fuzzy matching resolves the typo and records it as a soft match so the fix stays visible. A dedup guard stops the same report being counted twice when a vendor resends.

Matching engine · dedup guard
4
Archive and mirror

Clean rows append to the master archive, the single history of what was reported. A derived review sheet mirrors current state, so analysis never mutates the record it reads from.

Master archive · daily review
5
Reconciliation

A two-phase asynchronous sync pulls the enterprise system of record and compares it against reported actuals. Disagreements become explicit adjustment records, each with a reason. Bill-of-materials quantities reconcile against what crews actually used.

Reconciliation engine · async sync
6
Visibility and diagnostics

One engine decides which projects are eligible for the portfolio and generates a placeholder row for projects that should exist but carry no production history. Diagnostics classify every finding into the flags the surfaces render.

CaseStudy

Why a project manager built a platform

The problem everyone worked around

I managed about forty concurrent fiber builds across nine municipalities and four construction vendors. Vendors reported production every day, the enterprise system of record held the schedule, and nothing joined the two. Finding out whether one build was actually behind meant opening several spreadsheets, matching up project names that never quite agreed, and trusting a status field nobody had updated in a week.

That cost showed up in two places. Weekly meeting prep took six to eight hours of assembly by hand. And the daily review that should have caught problems early was too expensive to do properly, so problems surfaced late, usually as a surprise in front of a director.

The spreadsheets were never going to start agreeing on their own, so I built the thing that made them agree.

What I designed for

Nobody reads a delivery portfolio. They scan it, usually minutes before they have to answer for it. Anything a reader has to decode, remember across a gap or cross-reference is a cost, so state is encoded in form as well as number: a stripe on an edge, a texture in a fill, a letter in a bead, a glow on the frame. Form registers in peripheral vision before anyone reads a figure. And the encoding is the same everywhere, so nobody has to learn a new language on each screen.

On these screens every colour, radius, weight and border is there to carry meaning. At forty projects, one ornamental element is one more thing to filter out.

Findings are surfaced, never silently corrected. A resolved typo shows as a soft match, a derived stage shows as inferred, and a reconciliation writes an adjustment record with a reason. An automation that quietly fixes things teaches its operator to stop looking, and an operator who has stopped looking is worse than no automation at all.

The rule I held every automation to: never remove the human from the equation, only improve the output, so the project managers' time goes into decisions that change how a build turns out instead of day-to-day reconciliation of data. The design vocabulary above sets out seventeen of these devices, and Anatomy mode attaches each argument to the live component.

Keeping the forecast steady

OmniSight let me track field velocity across the whole portfolio. When one build started falling behind, I could reliably find another that was running ahead, or could, and move it up to take its place. That kept the forecast steady for the VP's presentation to the board. Recalled

My role

I was the Construction Project Manager. OmniSight was my own initiative, not an assigned project and not a company product. I conceived it, specified it, designed the interface and the data model, tested it, and ran it every day alongside the portfolio it served. I designed the system and set the rules it ran on. The AI and I brainstormed approaches, it tested the ideas and wrote the code, and because every change worked inside rules I set, I could answer for everything it did.

Schema adapter, trimmedAlias names changed
// Known header variants for each field the platform needs.
const SCHEMA_ALIASES = {
  PROJECT:    ["Project ID", "Job ID", "Work Order"],
  CONTRACTOR: ["Contractor", "Vendor", "Partner", "Company"],
  DATE:       ["Date", "Report Date", "Daily Work Date"],
  DAILY_UG:   ["UG Footage Today", "Bore Feet"],
};

SchemaAdapter.prototype.getIdx = function (name, options) {
  const want = name.toLowerCase().trim();

  // 1. The header exactly as written
  let idx = this.lowerHeaders.indexOf(want);
  if (idx !== -1) return idx;

  // 2. Any known alias for that field
  const aliases = SCHEMA_ALIASES[name.toUpperCase()] || [];
  for (const alias of aliases) {
    idx = this.lowerHeaders.indexOf(alias.toLowerCase());
    if (idx !== -1) return idx;
  }

  // 3. Partial match, guarded: a footage column is never a date or a BOM
  return this.lowerHeaders.findIndex(h =>
    (h.includes(want) || aliases.some(a => h.includes(a.toLowerCase()))) &&
    !(options?.isFootage && /date|target|bom|ofs/.test(h))
  );
};
Note 2

Vendors never agreed on column names

Every vendor labelled its columns differently, and they renamed them without warning. Finding a column by its position breaks the day someone inserts one, and it breaks quietly: footage lands in the wrong field and the dashboard still looks fine.

So every column lookup in the platform goes through one schema adapter. It tries the exact header, then the known aliases for that field, then a guarded partial match that won't mistake a date column for footage. A shifted or renamed column turns into a warning instead of bad data.

The code was the last of three layers. First we standardized the report form so vendors sent nearly the same shape. The adapter absorbed the variations that were left. When a header was missing entirely, the platform inferred it and flagged the guess for me to check against the archive, and drift that kept coming back became a permanent rule. Recalled

Note 3

The day the queue stopped running

On July 24 the queue module stopped working. The browser reported a syntax error inside Google's web app frame, but the same JavaScript parsed cleanly on my machine, and nothing in the queue logic had changed.

The obvious move was to start editing the queue code. I don't do that to something that was already running. Diagnose first, change second. The AI proposed reading the script text Google actually generated for the page and comparing it with the source, and I approved it.

One template literal held a web address. In the source it read `https://...`. In the served page it had been cut to `https:. HtmlService was evaluating that large script file as a template on its own, and the string didn't survive. One broken string was enough to stop the whole module.

The fix was small. The page shells still go through the template engine, but their CSS and script partials now load raw, through createHtmlOutputFromFile(...).getContent(). Fixing it was half the job. The other half was making sure the next one shows itself, so the rule went into the instructions the AI reads before every change: when code parses locally and fails in the frame, read the generated script first.

Handover

Before anyone else runs it

OmniSight worked because I ran it every day and knew where its assumptions lived. A tool that depends on one person isn't finished. Before handing it over, I would change four things. Recalled
